# Учебный проект «Умный дом» — Telegram-бот

Небольшой учебный проект на Python. Бот управляет виртуальным светом, показывает имитацию датчиков движения и двери, демонстрирует температуру, принимает голосовые команды и сохраняет события в SQLite.

> Важно: это демонстрационная модель. Без дополнительного оборудования она не управляет настоящими лампами и не считывает физические датчики.

## Возможности

- включение и выключение света кнопками;
- имитация датчика движения (при обнаружении движения бот включает свет);
- переключение состояния виртуальной двери;
- генерация тестового значения температуры;
- голосовые команды на русском языке;
- сохранение истории в базе данных smart_home.db;
- команды /start, /help, /status, /history.

## Что понадобится

- Python 3.10 или новее;
- Telegram;
- интернет для работы бота и распознавания речи;
- ffmpeg для обработки голосовых сообщений;
- токен бота, созданного через [@BotFather](https://t.me/BotFather).

## Запуск в Ubuntu / Linux

1. Скачай проект и открой терминал в папке проекта.
2. Установи ffmpeg и инструменты Python:

   sudo apt update
   sudo apt install python3 python3-venv python3-pip ffmpeg

3. Создай виртуальное окружение и установи библиотеки:

   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt

4. Создай бота в Telegram:
   - открой [@BotFather](https://t.me/BotFather);
   - отправь /newbot;
   - задай имя и username;
   - скопируй выданный токен.

5. Создай конфигурацию:

   cp .env.example .env
   nano .env

   Замени текст после TELEGRAM_BOT_TOKEN= на свой токен. Не публикуй токен и не загружай файл .env в GitHub.

6. Запусти бота командой python bot.py.
7. Открой созданного бота в Telegram и отправь /start.

## Как устроен код

- house — словарь с текущим состоянием виртуальных устройств.
- main_keyboard() — создаёт кнопки Telegram.
- handle_button() — обрабатывает нажатия кнопок.
- apply_voice_command() — сопоставляет распознанную фразу с действием.
- save_event() и read_history() — сохраняют и читают историю SQLite.
- main() — подключает обработчики и запускает бота.
